What is DevBox?

DevBox is an open-source collection of everyday developer utilities — all running directly in your browser. It covers formatting, inspection, encoding, security, API testing, CSS generation, color tools, converters, text utilities, and productivity tools.

It started as a personal project to avoid switching between a dozen bookmarked tabs, and grew into something more complete over time. The goal is to feel like a native developer tool, not a website.

Privacy philosophy
Your data stays in your browser. DevBox processes everything locally using JavaScript — your JSON, JWT tokens, passwords, source code, and API keys never leave your device and are never sent to any server.

The only exceptions are tools that intentionally make network requests by design: the API Tester, GraphQL Playground, WebSocket Client, and Network Tools send requests to the URLs you specify. For those, take the same care you would with any HTTP client.
Built with
Vanilla HTML / CSS / JS No frameworks Progressive Web App Service Worker GitHub Pages Zero dependencies

No npm, no bundler, no framework. Every tool is a standalone HTML file. This keeps the project fast to load, easy to audit, and trivial to self-host.

Install & extend

DevBox is a fully installable PWA — add it to your home screen or desktop for instant offline access to every tool. It also ships as a browser extension, giving you right-click access to DevBox tools directly from any page.
