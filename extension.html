How to install
  1. Download the .zip above, then unzip it — you should end up with a devbox-extension folder on your computer.
  2. Open chrome://extensions in Chrome (or edge://extensions for Edge, brave://extensions for Brave).
  3. Turn on Developer mode using the toggle in the top-right corner.
  4. Click Load unpacked and select the unzipped devbox-extension folder (not the .zip itself).
  5. The DevBox icon appears in your toolbar — click the puzzle-piece icon and pin it for one-click access.
What it does
⚡ Toolbar popup Jump straight to 10 commonly-used tools — JSON, Regex, UUID, Password, Base64, JWT, Diff, Date/Time, Hash, and Color — without opening a tab first.
🖱️ Right-click on selected text Select any text on any page, right-click → DevBox, and choose Format as JSON, Base64 Decode, URL Decode, Decode JWT, or Hash — it opens the tool with your text already filled in.
🔒 The extension sends no data anywhere. Selected text is passed directly into a new tab opened to devmina.github.io/devbox — nothing is transmitted to any server the extension controls.
